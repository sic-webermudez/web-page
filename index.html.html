1. Quiénes somos

Somos SIC Web and Software, un desarrollador independiente con sede en Nicaragua. Creamos sistemas, aplicaciones móviles y páginas web. El responsable del tratamiento de los datos es Sergio Bermúdez.

2. A qué aplica esta política

Esta política aplica a todas las aplicaciones móviles que publicamos en Google Play bajo el nombre de desarrollador SIC Web and Software, y a este sitio web. Si una aplicación necesita tratar datos de una forma distinta, lo indicaremos dentro de la propia aplicación.

3. Datos que recopilamos

Datos que usted escribe en la aplicación

Por ejemplo, nombres de clientes, productos, pedidos, precios o notas que usted registra para usar la aplicación. Estos datos son suyos: los usamos solo para que la aplicación funcione.

Datos que recopilamos automáticamente

Podemos recibir información técnica básica, como el modelo del dispositivo, la versión de Android y reportes de errores, para corregir fallos y mejorar el rendimiento.

Lo que no hacemos

  • No vendemos sus datos personales.
  • No usamos sus datos para crear perfiles publicitarios.
  • No pedimos datos que la aplicación no necesite para funcionar.

4. Permisos del dispositivo

Según la aplicación, Android puede pedirle alguno de estos permisos. Siempre podrá aceptarlos o rechazarlos, y cambiarlos después desde los ajustes del teléfono.

  • Ubicación: para calcular distancias o mostrar información cercana. Se usa solo mientras la función está en uso.
  • Cámara: para tomar fotos o escanear códigos, por ejemplo de productos.
  • Almacenamiento o archivos: para guardar o exportar documentos, como catálogos o reportes.
  • Internet: para sincronizar datos con nuestros servidores y recibir actualizaciones.
  • Notificaciones: para enviarle recordatorios o avisos de la aplicación.

Solo se solicitan los permisos que cada aplicación necesita. Los datos obtenidos con ellos se usan únicamente para la función que los pidió.

5. Cómo usamos los datos

  • Hacer funcionar las funciones de la aplicación que usted utiliza.
  • Guardar su información para que la encuentre al volver a abrir la aplicación.
  • Detectar y corregir errores.
  • Responder sus consultas de soporte.
  • Cumplir con obligaciones legales, si llegaran a aplicar.

6. Terceros

No compartimos sus datos personales con terceros, salvo con proveedores de servicios que hacen posible la aplicación y que tratan los datos solo bajo nuestras instrucciones:

  • Google (Google Play y servicios de Android), para distribuir la aplicación y, si aplica, mostrar reportes de fallos.
  • Proveedores de alojamiento y bases de datos en la nube (por ejemplo Supabase o Firebase), para guardar y sincronizar la información.

Cada uno de estos proveedores tiene su propia política de privacidad. Podríamos divulgar datos si una autoridad competente lo exige conforme a la ley.

7. Seguridad

Usamos conexiones cifradas (HTTPS) y controles de acceso para proteger la información. Ningún sistema es totalmente infalible, pero trabajamos para reducir los riesgos y corregir cualquier problema de seguridad que detectemos.

8. Conservación y eliminación de datos

Conservamos sus datos mientras use la aplicación o mientras sea necesario para darle el servicio. Puede pedirnos que eliminemos su cuenta y sus datos asociados en cualquier momento:

  • Escriba a sicwebandsofware@gmail.com con el asunto «Eliminar mis datos».
  • Indique el nombre de la aplicación y el correo o usuario con el que se registró.

Atenderemos su solicitud en un plazo máximo de 30 días. Si una aplicación funciona sin cuenta y guarda los datos solo en su teléfono, basta con desinstalarla o borrar sus datos desde los ajustes de Android.

9. Menores de edad

Nuestras aplicaciones no están dirigidas a menores de 13 años y no recopilamos datos de ellos de forma intencional. Si cree que un menor nos entregó información, escríbanos y la eliminaremos.

10. Sus derechos

Usted puede pedirnos acceder a sus datos, corregirlos, eliminarlos u oponerse a su uso. Para ejercer estos derechos, use el correo de contacto de esta página. Tomamos en cuenta la normativa de protección de datos personales vigente en Nicaragua.

11. Cambios en esta política

Podemos actualizar esta política cuando cambien nuestras aplicaciones o la ley. Publicaremos la versión nueva en esta misma página y cambiaremos la fecha de «Última actualización». Si el cambio es importante, se lo avisaremos también dentro de la aplicación.
